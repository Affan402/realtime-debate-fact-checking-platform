# CI/CD Pipeline

## Overview
This project uses GitHub Actions to automatically build, test, and package
the application on every push and pull request to the `main` branch.

The pipeline runs 3 jobs in parallel:
1. **Build** — compiles the frontend
2. **Test** — runs backend unit tests
3. **Docker** — builds and pushes container images

## Jobs

### 1. Build (Frontend)
- **Runner:** ubuntu-latest, Node.js 22
- **Steps:**
  - Checkout code
  - Install dependencies (`npm ci`)
  - Build the app (`npm run build`)
- **Purpose:** Catches TypeScript and build errors

### 2. Test (Backend)
- **Runner:** ubuntu-latest, Node.js 22
- **Steps:**
  - Checkout code
  - Install dependencies (`npm ci`)
  - Run Jest tests (`npm test`)
- **Secrets used:** `MONGODB_URI` (injected as `URI` env var)
- **Purpose:** Catches logic bugs in backend code

### 3. Docker
- **Runner:** ubuntu-latest
- **Steps:**
  - Checkout code
  - Set up Docker Buildx
  - Login to GitHub Container Registry
  - Build backend + frontend images
  - Tag with `latest` and commit hash
  - Push to GHCR
- **Secrets used:** `GITHUB_TOKEN` (auto-generated)
- **Purpose:** Creates deployable container images

## Secrets
| Name | Purpose | Setup |
|------|---------|-------|
| `MONGODB_URI` | MongoDB Atlas connection string | Manual (repo settings) |
| `GITHUB_TOKEN` | Push access to GHCR | Auto-generated by GitHub |
